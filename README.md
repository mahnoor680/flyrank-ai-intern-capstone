# FlyRank AI Intern Capstone



## Overview



This repository is part of the FlyRank AI Intern Capstone assignment.



The project demonstrates a basic AI-assisted development workflow using Git,

GitHub, and an AI coding assistant.



## Goals



- Practice Git and GitHub workflows.

- Use Conventional Commits.

- Work with AI-assisted development tools.

- Maintain clear and useful project documentation.



## Development Workflow



Changes are developed locally, reviewed, committed with meaningful Git

messages, and pushed to GitHub.



## AI Assistance



An AI coding assistant is used to review and improve the project documentation

while keeping the changes clear, simple, and maintainable.
