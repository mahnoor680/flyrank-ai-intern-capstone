# Project Instructions



## General



- Keep the project simple, clear, and maintainable.

- Use Conventional Commits for Git commit messages.

- Do not introduce unnecessary dependencies.

- Review changes before committing them.



## Documentation



- Keep README.md up to date.

- Use clear Markdown headings.

- Keep documentation concise and professional.

- Explain important project changes clearly.



## AI-Assisted Development



- Review existing files before making changes.

- Explain proposed changes before applying significant modifications.

- Prefer small, focused changes.

- Do not modify files unrelated to the requested task.



## Workflow



When making changes to this repository:



1. Inspect the relevant files first.

2. Make the smallest reasonable change.

3. Review the result before committing.

4. Use a clear Conventional Commit message.
